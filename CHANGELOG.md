# Changelog

## 0.2.0 — 2026-10-26

First public experimental handoff: **Swipe Me, Maybe**.

### Included

- Python standard-library runner, local dashboard and offline demo.
- Preview, manual calibration, stop, time/count limits and conservative failures.
- Appium/XCUITest bridge with Windows preinstalled-WDA support.
- Read-only Windows prerequisite doctor and unsigned WDA-to-IPA preparation.
- Synthetic tests, Windows/Linux CI, setup guides and contributor tooling.

### Still open

Signed WDA installation, tunnel/device connection and the actual Hinge flow
have not completed physical acceptance. This release contains no signed app,
Apple account, credentials or ready-made selectors for somebody else's phone.
See the [handoff](docs/HANDOFF.md) and [roadmap](docs/ROADMAP.md).
