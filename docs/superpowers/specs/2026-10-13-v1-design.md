# iPhone Like Assistant v0.1 — design

User intent: the owner opens Hinge on his own unlocked iPhone, starts a bounded
session from his Mac, and the tool sends ordinary likes without profile ranking.
The first version must be small, inspectable and local; not a general AI agent.

Architecture: Python 3.11+ standard library; a localhost browser dashboard;
Appium 3/XCUITest/WebDriverAgent on the Mac. No model, cloud service, passwords,
screenshots or Hinge private API. Device signing and real-phone calibration are
local prerequisites and cannot be performed in this environment.

Manual calibration captures a Discover marker, a normal heart button and the
ordinary Send Like button from real accessibility elements. Exact labels only;
unknown/dynamic layouts stop, rather than introducing blind coordinate clicks.
Only captured visible button layouts are accepted. Non-empty comment fields,
alerts, another app, a locked phone, a failed request, an unchanged next profile,
a stop request or a time/count limit stop the session. No purchase/rose/message
button can be chosen as a target. No retry of a possibly completed click.

Default: read-only preview; live sessions require a separate explicit checkbox.
Default session: 5 send attempts, 120 seconds. Hard bounds: 25 attempts, 600 seconds.
A send attempt and an observed return to a changed feed are separate counters;
neither proves Hinge's server accepted a like. Stop cannot revoke an in-flight
request. A fixed short wait is UI settling, not anti-detection behavior.

Local files: device.local.json and selectors.local.json, ignored by Git.
Accessibility text is processed in memory; only control calibration is persisted.
Appium should run at warn logging, with automatic screenshots disabled. Third
party Xcode/Appium diagnostics may still exist locally. Never upload those.

V1 excludes voice/Siri, autonomous startup, messages, scraping/profile databases,
remote network access, rate-limit bypass, CAPTCHA handling and anti-bot evasion.
Hinge prohibits automation and may ban accounts, including for creating tools.

Delivery is now a public MIT source handoff. See ../../HANDOFF.md and
../../ROADMAP.md for the current continuation and acceptance gap.
