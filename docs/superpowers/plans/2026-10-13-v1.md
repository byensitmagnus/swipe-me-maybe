# Original local prototype: implementation record

Architecture: Python stdlib decision/runner core, narrow Appium bridge and
localhost dashboard. Design: ../specs/2026-10-13-v1-design.md.

- [x] Exact-selector screen recognition and bounded runner.
- [x] Stop, deadline, wrong-app, draft-input and ambiguous-send handling.

- [x] Local calibration and Host/Origin/session-token checks.
- [x] Synthetic unit and HTTP integration tests.

Later Windows setup, browser acceptance and public-source handoff supersede
this original delivery stage. See ../../../VERIFICATION.md and ../../HANDOFF.md.
