# Be decent to each other

This project is allowed to joke about code, overworked thumbs and its own
questionable optimism. It is not an invitation to ridicule people on dating apps.

- Be welcoming and constructive. Critique the change, not the contributor.
- Respect privacy and consent. Never post profiles, private messages or identifiers.
- No harassment, discrimination, threats or sexualized comments about others.
- Keep issues and pull requests relevant and reproducible.

Maintainers may remove inappropriate content, close disruptive discussions or
restrict participation. Use GitHub's reporting tools for abusive content;
do not reproduce sensitive material in a public issue to report it.
