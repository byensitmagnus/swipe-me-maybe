LOKAL PROTOTYPE · V0.2 · WINDOWS + IPHONE

iPhone Like Assistant

Åbn Hinge på din iPhone. Du vælger knapperne én gang; en afgrænset session gentager forløbet.

Ikke forbundet
DEMO — ingen iPhone er tilsluttet, og der sendes ingen rigtige likes.

Her afprøver du kontrolpanelet med kunstige skærme. Start uden --demo for den rigtige driver.

Hinge forbyder autoswipers og kan spærre din konto. V1 omgår ikke begrænsninger. Den sender ikke beskeder eller roser og foretager ikke køb. Første test skal ske, mens du følger med.

Klar til opsætning.

01

Forbind din iPhone

Appium skal køre lokalt på port 4723. På Windows skal en signeret WebDriverAgent allerede være installeret, og RemoteXPC-tunnelen skal køre. Telefonen skal være tilsluttet via USB, betroet og i udviklertilstand.

Windows kræver iOS 18+ og WDA bundle-id. Team ID bruges kun på Mac. Intet Apple-password skal indtastes her.

02

Lær de rigtige knapper

Kalibreringen bruger de faktiske knapnavne fra din app — ikke gættede koordinater.

Ingen kalibrering endnu.

A. På Discover-profilsiden

Åbn Discover på telefonen. Aflæs skærmen og vælg den aktive Discover-fane samt et almindeligt hjerte.

B. På Send Like-skærmen

Tryk selv på et almindeligt hjerte på iPhonen, men send ikke. Aflæs igen, vælg Send Like og gem. Luk derefter dialogen manuelt.

Se knapper fra seneste aflæsning
Ingen aflæsning.

Kan en knap ikke findes, eller skifter knapnavnene mellem profiler, stopper v1. Den gætter ikke og kræver da en lokal tilpasning.

03

Start en afgrænset session

Gå tilbage til Discover-profilsiden på din iPhone inden start. Lad computeren og iPhone være vågne, og brug ikke telefonen imens.
